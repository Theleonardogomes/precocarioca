# 🛒 PreçoCarioca (CariocaEconomiza)

Aplicação web colaborativa e inteligente desenvolvida para comparar preços de supermercados no Estado do Rio de Janeiro (Capital e Baixada Fluminense). Criado com foco em portfólio para demonstrar habilidades avançadas em engenharia frontend, arquitetura de dados e inteligência artificial aplicada.

## 🚀 Funcionalidades do Sistema

- **10 Redes Monitoradas**: Guanabara, Atacadão, Dom Atacadista, Assaí Atacadista, Adonai, Mundial, Rede Economia, Super Market, Prezunic e Zona Sul.
- **Otimizador Inteligente de Lista**: Calcula simultaneamente a **Compra Dividida** (economia máxima comprando em estabelecimentos diferentes) vs. **Melhor Mercado Único**.
- **Scanner Inteligente de Nota Fiscal (NFC-e RJ)**: Extração automática de preços por IA a partir de fotos de cupons fiscais.
- **Gamificação e Pexo-Score**: Sistema de perfis de usuários com acúmulo de XP por notas fiscais enviadas e histórico de contribuições.
- **Gráficos e Histórico de Preços**: Visualização vetorial (SVG) da variação de preços nos últimos 30 dias.

## 🛠️ Tecnologias Utilizadas
- **HTML5, Tailwind CSS e JavaScript (Vanilla)**
- **LocalStorage** para persistência de dados no navegador
- **Design Responsivo** otimizado para dispositivos móveis e desktop
